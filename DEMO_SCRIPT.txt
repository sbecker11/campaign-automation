DEMO SCRIPT — 3 MINUTES, NO PAUSES (LIVE DELIVERY)

00:00 — TITLE & CONTEXT (5s)
+---------------------------------------------------------------
|| CAMPAIGN AUTOMATION PROJECT: GENERATE IMAGES, REVIEW FAST, MARK DELETES.
||
|| open https://github.com/sbecker11                          
|| open https://github.com/sbecker11/campaign-automation 
|| copy git path                         
+---------------------------------------------------------------

00:05 — INSTALL (15s)
+----------------------------------------------------------------
|| MAKE A DEMO-WORKSPACE FOLDER
||
|| cd ~
|| mkdir demo-workspace
+------------------------------------------------------
+------------------------------------------------------
|| CLONE THE GITHUB PROJECT INTO THE DEMO-WORKSPACE FOLDER
||
|| cd demo-workspace
|| git clone https://github.com/sbecker11/campaign-automation.git
+------------------------------------------------------
+------------------------------------------------------
|| RUN ONE-COMMAND SETUP
|| (Creates venv, installs dependencies, sets up pre-commit hook)
||
|| cd campaign-automation
|| ./setup.sh
+------------------------------------------------------
+------------------------------------------------------
|| ADD OPENAI_API_KEY TO LOCAL .env FILE 
||
|| cp ../workspace-campaign-automation/.env .
|| cat .env
+------------------------------------------------------

00:20 — TESTS (20s)
+------------------------------------------------------+
|| NOW WE'LL RUN ALL TESTS WITH COVERAGE
||
|| ./scripts/run_tests_w_coverage.sh                    
+------------------------------------------------------+

00:40 — GENERATE (35s)
--------------------------------------------------------
|| REVIEW THE LATEST campaign.yml FILE
||
|| cat campaign-automation/inputs/campaigns/example_campaign.yaml
--------------------------------------------------------

--------------------------------------------------------
|| GENERATE THE PRODUCT IMAGES AND APPLY COMPLIENCE CHECKS
|| USE OPENAI (DALL·E 3) TO GENERATE IMAGES (WITH REGEN IF COLOR BARS)
|| USE PILLOW TO DETECT EDGE COLOR BARS AND TRIGGER REGEN
|| USE PILLOW TO CENTER AND WRAP OVERLAY TEXT WITH BACKGROUND
|| USE PILLOW TO VALIDATE LOGO FILE (FORMAT, SIZE) BEFORE ADD
|| USE OPENCV TO DETECT LOGO PRESENCE VIA TEMPLATE MATCHING
|| USE OPENCV TO SCORE SHARPNESS (LAPLACIAN VARIANCE)
|| USE PILLOW TO ADD SEMI-TRANSPARENT BACKGROUND BEHIND LOGO IF NEEDED
|| USE CONTENT CHECKER TO FLAG PROHIBITED WORDS
|| USE REPORT GENERATOR TO WRITE JSON (GENERATION + COMPLIANCE)
|| USE PIPELINE TO ORGANIZE OUTPUTS PER CAMPAIGN/TIMESTAMP 
||
|| ./scripts/generate_campaign.sh                       
+-------------------------------------------------------

01:15 — REFINE (45s)
+-------------------------------------------------------
|| NOW WE'LL REVIEW THE NEWLY-GENERATED CAMPAIGN IMAGES:
||
|| HIDE OR SHOW IMAGES
||
|| ADD COMMENTS
||
||
|| SAVE THE CAMPAIGN USING THE "SAVE CAMPAIGN" button
||
||
|| COMMIT CAMPAIGN CHANGES TO
|| GIT HUB USING THE "COMMIT CAMPAIGN" BUTTON
||
||
|| USE THE "EXIT" BUTTON TO EXIT THE REFINE_CAMPAIGN WEB APP.
||
|| ./scripts/refine_campaign.sh                         
+-------------------------------------------------------

02:00 — CLOSEOUT (20s)
+------------------------------------------------------+
|| SAVE THIS CAMPAIGN TO A UNIQUE GITHUB BRANCH
||
|| CAMPAIGN_NAME="LATEST-CAMPAIGN-$(iso8601)"
|| git checkout -b ${CAMPAIGN_NAME}
|| git add .        
|| git commit -m "Generated and refined latest campaign images"
+------------------------------------------------------+

That's the loop. Repeat Generate → Refine. Commit if desired.
